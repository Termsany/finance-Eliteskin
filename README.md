# المتابعة المالية — Elite Skin

برنامج ويب لمتابعة المصاريف والمديونيات والأرباح، مربوط بدفترة (Daftra) يسحب البيانات تلقائيًا، مع مساعد ذكاء اصطناعي للتحليل والاقتراحات.

## المميزات
- **داش بورد** بأهم الأرقام: مبيعات، مشتريات، مصاريف، صافي ربح، وتوقع سيولة.
- **زرّان كبيران** لتقرير مديونيات العملاء ومستحقات الموردين، بالألوان: 🔴 متأخر أكثر من شهر، 🟡 أقل من شهر، 🟢 في موعده — مع تصدير PDF وكشف حساب لكل طرف.
- **المصاريف** بثلاثة أنواع: ثابت متكرر، مؤقت بمدة وينتهي، ومرة واحدة.
- **البيع والشراء** و**الربح والخسارة** شهريًا من فواتير دفترة.
- **مساعد ذكي** يحلل بياناتك الحقيقية ويقترح أين توفّر وكيف تزيد الربح.
- **مزامنة تلقائية** من دفترة كل ساعة + زر تحديث فوري.

## كيف يعمل الربط بدفترة
البرنامج يقرأ من دفترة فقط (لا يعدّل فيها) عبر Daftra API v2:
`https://{subdomain}.daftara.com/api2` بترويسة `apikey`.
يسحب: العملاء، الموردين، فواتير البيع (مديونيات العملاء)، فواتير الشراء (مستحقات الموردين).
المصاريف تُدار داخل البرنامج (مش في دفترة) وتُحفظ في `data/db.json`.

## المتطلبات
- سيرفر Ubuntu/Debian (الـ VPS بتاعك على Hostinger يكفي).
- مفتاح Daftra API: من دفترة → الإعدادات → مفاتيح الـ API.
- (اختياري) مفتاح Anthropic لتفعيل الذكاء الاصطناعي: https://console.anthropic.com

## إضافة المفاتيح (دفترة + AI) من داخل البرنامج
بعد تسجيل الدخول، افتح صفحة **الإعدادات** من القائمة:
- اكتب **الساب دومين** ومفتاح **دفترة**، واضغط **اختبار الاتصال** ثم **حفظ** — المزامنة تبدأ فورًا.
- اكتب مفتاح **Anthropic** لتفعيل الذكاء الاصطناعي الكامل.
المفاتيح تُحفظ على السيرفر في `data/db.json` ولا تظهر في الواجهة بعد الحفظ. (يمكن بدلًا من ذلك وضعها في `.env`.)

## التثبيت على الـ VPS
```bash
# 1) ارفع المجلد للسيرفر (أو فك الأرشيف elite-finance.tar.gz)
cd elite-finance

# 2) ثبّت
sudo bash deploy/install.sh

# 3) عدّل الإعدادات (بيانات دفترة والمفاتيح وكلمة المرور)
sudo nano /opt/elite-finance/.env

# 4) شغّل
sudo systemctl restart elite-finance
sudo journalctl -u elite-finance -f   # للتأكد إنه اشتغل وزامن مع دفترة
```
ثم إعداد Nginx والدومين كما في `deploy/install.sh` (آخر رسالة بعد التثبيت).

## التشغيل محليًا للتجربة
```bash
npm install
cp .env.example .env   # واملأ القيم
npm start              # يفتح على http://localhost:3200
```

## التحديث لاحقًا
```bash
cd elite-finance && sudo bash deploy/update.sh
```
التحديث لا يمس `.env` ولا مجلد `data/`.

## الأمان
- الدخول بكلمة مرور (`APP_PASSWORD`). غيّرها لكلمة قوية.
- المفاتيح (دفترة/Anthropic) تُحفظ في `.env` على السيرفر فقط — لا تضعها في أي مكان عام ولا ترفعها على Git.
- شغّل HTTPS عبر `certbot` كما في خطوات التثبيت.

## معايرة حقول دفترة
بعد الربط، لو ظهرت أرقام مديونية غير متوقعة، افتح (وأنت داخل البرنامج):
`/api/daftra/sample` — يعرض عينة خام من أول فاتورة بيع وشراء، لمطابقة أسماء الحقول (مثل المبلغ المتبقي وتاريخ الاستحقاق) وضبطها في `src/daftra.js`.
