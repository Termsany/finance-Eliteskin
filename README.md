# المتابعة المالية — Elite Skin (v2)

مرجع واحد لكل الحسابات، مربوط بدفترة (قراءة بس، مش بيعدّل فيها حاجة):

- **الملخص**: صافي الربح، اللي ليك عند العملاء، اللي عليك للموردين، والمصروفات — كل رقم مقارن بالفترة اللي قبلها، ورسم شهري، وقائمة «محتاج انتباهك النهارده».
- **العملاء والموردين**: أعمار الديون، أرصدة كل واحد، وكشف حساب بالرصيد بعد كل حركة، والفواتير المفتوحة، ورسالة تذكير بالسداد جاهزة للواتساب.
- **المصروفات**: مصروفات دفترة + مصروفات البرنامج بأنواعها (ثابت كل شهر، مؤقت لمدة، مرة واحدة).
- **الأرباح والخسائر**: قائمة دخل كاملة بتكلفة البضاعة الحقيقية لكل صنف (مش مبيعات ناقص مشتريات)، كل شهر في عمود.
- **الضريبة** شهر بشهر، **السيولة** 13 أسبوع قدام، **المنتجات والأسعار** (البيع تحت التكلفة والمخزون)، و**مراجعة الحسابات**.
- **المستشار المالي** بالذكاء الاصطناعي، **بحث** واحد بالاسم أو رقم الفاتورة، **Excel**، و**وضع ليلي**.
- **الإعدادات**: ربط دفترة، والذكاء الاصطناعي، وتغيير كلمة المرور، وبداية الحسابات، والأهداف.

## الترقية من النسخة الأولى (مرة واحدة على السيرفر)

```bash
curl -fsSL https://raw.githubusercontent.com/Termsany/finance-Eliteskin/main/deploy/install.sh | sudo bash
```

السكريبت:
1. بيثبت Docker لو مش موجود، وبينزّل البرنامج في `/opt/elite-finance-v2`.
2. بياخد كلمة المرور وسر الجلسات من `.env` النسخة الأولى، ويعمل باسورد لقاعدة البيانات.
3. بيوقف النسخة الأولى ويشغّل الجديدة على نفس المنفذ `3200` — nginx والدومين `finance.eliteskinsa.com` زي ما هم.
4. أول تشغيل بينقل تلقائياً من `data/db.json`: المصاريف، وربط دفترة، ومفتاح الذكاء الاصطناعي.
5. لو النسخة الجديدة ما اشتغلتش، بيرجّع الأولى لوحده.

النسخة الأولى وملفاتها بتفضل زي ما هي في `/opt/elite-finance` (ما بتتمسحش).

## التحديث بعد كده

```bash
sudo bash /opt/elite-finance-v2/deploy/update.sh
```

## التشغيل محلياً

```bash
npm install
cp .env.example .env   # واملأ القيم، و DATABASE_URL لقاعدة Postgres
npm run db:migrate
npm run dev            # http://localhost:3200
```

`npm test` للاختبارات، `npm run typecheck` و `npm run lint` للفحص.

## ملاحظات
- البرنامج بيتزامن مع دفترة كل ساعة، وفيه زرار «حدّث من دفترة» للتحديث الفوري.
- مفاتيح دفترة والذكاء الاصطناعي بتتحفظ مشفّرة في قاعدة البيانات. ما تغيّرش `SESSION_SECRET` بعد التشغيل.
- لو مصروف متسجل في دفترة، ما تضيفوش في «مصروفات البرنامج» عشان ما يتحسبش مرتين.
